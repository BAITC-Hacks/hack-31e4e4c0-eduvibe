# API-контракт frontend ↔ backend

Контракт согласован для конкурсного MVP EduVibe. Все пути имеют префикс `/api/v1`, тела передаются как JSON, время — ISO 8601 UTC.

## Общие правила

- Backend URL локально: `http://localhost:8000/api/v1`.
- Swagger: `http://localhost:8000/docs`.
- После редактирования карточка требует нового подтверждения.
- После публикации карточка неизменяема в MVP; попытка редактирования или сохранения ответов возвращает `409 TASK_ALREADY_PUBLISHED`.
- Низкий рейтинг не запрещает публикацию или отклик.
- Каталог возвращает только опубликованные задачи, по убыванию рейтинга.
- `ai_mode` равен `live` для OpenAI и `fallback` для явно обозначенного резервного режима.

## Единый формат ошибки

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Проверьте введённые данные.",
    "details": [{"field": "description", "message": "String should have at least 10 characters"}]
  }
}
```

Основные коды: `VALIDATION_ERROR` — 422, `*_NOT_FOUND` — 404, нарушение состояния — 409, проблемы AI — 502/503/504.

## Структуры

### Карточка `card`

```json
{
  "title": "Каталог практических задач",
  "context": "Как процесс работает сейчас",
  "need": "Что нужно изменить",
  "users": "Кто пользуется решением",
  "data_materials": "Доступные данные и примеры",
  "constraints": "Сроки, технологии и доступы",
  "expected_result": "Конкретный результат",
  "success_criteria": "Измеримые признаки успеха",
  "contact": "Контакт бизнеса",
  "interaction_format": "Формат консультаций и обратной связи"
}
```

Все поля — строки. Лимит исходного описания — 5000 символов.

### Рейтинг `readiness`

```json
{
  "total": 55,
  "level": "working",
  "level_label": "Рабочая",
  "breakdown": [
    {
      "field": "context",
      "label": "Контекст",
      "points": 10,
      "max_points": 10,
      "hint": null
    }
  ],
  "missing_information": ["Критерии успеха"],
  "suggestions": ["Добавьте измеримые признаки успешного результата."]
}
```

Уровни: `draft` 0–39, `working` 40–69, `ready` 70–89, `priority` 90–100.

### Задача

Ответ задачи содержит:

```json
{
  "id": "uuid",
  "description": "Исходное описание",
  "topic": "Образование",
  "card": {},
  "questions": [],
  "answers": [],
  "readiness": {},
  "is_confirmed": false,
  "is_published": false,
  "ai_mode": null,
  "created_at": "2026-09-23T10:00:00",
  "updated_at": "2026-09-23T10:00:00"
}
```

## Endpoints

| Метод | Путь | Вход | Результат |
|---|---|---|---|
| GET | `/health` | — | `{"status":"ok","database":"ok"}` |
| POST | `/tasks` | `description`, `topic` | 201, черновик с исходным рейтингом |
| GET | `/tasks/{id}` | — | Задача |
| POST | `/tasks/{id}/clarifications` | — | `questions` (не менее 3), `ai_mode` |
| PUT | `/tasks/{id}/answers` | `answers[]: {question_id, field, text}` | Обновлённая карточка и предварительный рейтинг |
| PATCH | `/tasks/{id}` | `{"card": {...}}` | Сохранённая карточка; подтверждение сбрасывается |
| POST | `/tasks/{id}/confirm` | — | Подтверждённая карточка и зафиксированный рейтинг |
| POST | `/tasks/{id}/publish` | — | Опубликованная задача; без порога баллов |
| GET | `/tasks?topic=...&readiness_level=...` | Оба фильтра необязательны | Каталог |
| GET | `/teams` | — | Пять демонстрационных профилей |
| POST | `/tasks/{id}/proposals` | `team_id`, `idea`, `plan`, `duration_days`, `prototype_url` | 201, отклик |
| GET | `/tasks/{id}/proposals` | — | Отклики с профилями команд |
| PUT | `/tasks/{id}/decision` | `selected_proposal_ids[]`, `rejected_proposal_ids[]` | Все отклики с новыми статусами |
| PUT | `/proposals/{id}/milestone` | `result`, `points` (1–100) | Подтверждённый этап и общий балл команды |

### Пример уточняющих вопросов

```json
{
  "questions": [
    {"id": "q-1", "field": "users", "text": "Кто будет пользоваться результатом решения?"},
    {"id": "q-2", "field": "data_materials", "text": "Какие данные доступны команде?"},
    {"id": "q-3", "field": "success_criteria", "text": "По каким признакам вы примете результат?"}
  ],
  "ai_mode": "live"
}
```

### Решение бизнеса

```json
{
  "selected_proposal_ids": ["proposal-1"],
  "rejected_proposal_ids": ["proposal-2"]
}
```

Пустые массивы допустимы и означают, что бизнес пока никого не выбрал. Один ID нельзя передать в обоих массивах. Автоматического выбора нет.

## Правило рейтинга

Баллы начисляются за непустые поля последней подтверждённой версии:

| Поле | Баллы |
|---|---:|
| Контекст | 10 |
| Потребность | 10 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Контакт бизнеса | 5 |
| Формат взаимодействия | 5 |

Название и тема обязательны для представления задачи, но не входят в 100 баллов.
