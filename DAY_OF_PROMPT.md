# Стартовый запрос к Codex в день хакатона

Скопируйте опубликованное условие в `TASK_BRIEF.md`, затем отправьте Codex следующий запрос.

```text
Изучи AGENTS.md, HACKATHON_RULES.md, TASK_BRIEF.md, API_CONTRACT.md и TASKS.md.

Мы участвуем в пятичасовом хакатоне в треке «Образование». В команде два человека:
- Dex отвечает за Python/FastAPI/OpenAI/MySQL/Docker и интеграцию;
- B_l_a_c_kS_u_n отвечает за React/TypeScript/Vite и интерфейс.

Сначала не пиши код. Проведи анализ опубликованной задачи:
1. Дословно выдели обязательные условия допуска.
2. Преобразуй требования в таблицу: требование → проверяемый результат → способ проверки → риск.
3. Укажи неясности, которые нужно уточнить у организаторов.
4. Предложи один минимальный сквозной пользовательский сценарий, который можно надёжно реализовать за 5 часов.
5. Раздели функции на MUST, SHOULD и WON'T.
6. Предложи минимальную архитектуру на основе имеющегося стека. Не добавляй технологии без необходимости.
7. Составь параллельный план работы для двух участников с контрольными результатами каждого часа.
8. Определи API-контракт, чтобы frontend и backend могли начать параллельно.
9. Перечисли главные риски воспроизводимости, OpenAI API, данных и демонстрации.

Не выдумывай требования и не заявляй функции, которых нет в условии. После анализа остановись и запроси подтверждение архитектуры и MVP.
```

## Запрос после согласования плана

```text
План и API-контракт согласованы. Обнови TASKS.md и API_CONTRACT.md. Затем реализуй только назначенную мне часть проекта, соблюдая ближайший AGENTS.md.

Перед изменениями перечисли затрагиваемые файлы. После изменений запусти доступные проверки, сообщи фактический результат и предложи текст небольшого осмысленного Git-коммита. Не изменяй файлы другого участника без прямой необходимости.
```
