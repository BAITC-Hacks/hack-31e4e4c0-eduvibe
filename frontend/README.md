# EduVibe frontend

React + TypeScript + Vite-интерфейс для ролевого сценария EduVibe.

## Запуск

```bash
cd frontend
npm install
npm run dev
```

По умолчанию приложение использует `http://localhost:8000/api/v1`. Для другого адреса скопируйте `.env.example` в `.env` и задайте `VITE_API_URL`. Открывайте dev-сервер по адресу `http://localhost:5173`: backend должен разрешать этот origin в CORS.

## Роли и сценарии

На стартовом экране frontend загружает демонстрационные профили из `GET /demo/profiles` и создаёт временную Bearer-сессию через `POST /session`. Токен хранится только в `sessionStorage`, восстанавливается через `GET /session` и удаляется через `DELETE /session`.

- Бизнес: мои кейсы → создание черновика → AI-уточнения → ответы и рейтинг → редактирование функциональной карты → подтверждение → публикация → просмотр откликов → ручное решение → подтверждение milestone.
- Студенческая команда: каталог опубликованных задач → просмотр полной карточки → отправка одного предложения от текущей команды → история своих откликов и решений бизнеса.

Интерфейс использует визуальный язык Orbit Network из корневого `DESIGN.md`, но каждый узел карты связан с реальным полем API. Доступные разделы и действия зависят от роли и владельца кейса. Каталог отправляет фильтры `topic` и `readiness_level` в backend. Для каждого отклика бизнес независимо выбирает состояние «на рассмотрении», «выбрана» или «отклонена»; автоматического назначения и автоматического отклонения остальных команд нет.

После публикации карточка отображается только для чтения. История команды сохраняет отклик, даже если исходная задача была удалена бизнесом. Ошибки API, истёкшая сессия, резервный AI-режим, загрузка и пустые состояния показываются явно.
