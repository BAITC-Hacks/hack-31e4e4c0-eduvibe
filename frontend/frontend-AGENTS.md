# Инструкции Codex для `frontend/`

## Ответственный

Основной владелец frontend: B_l_a_c_kS_u_n.

## Стек

- React;
- TypeScript;
- Vite;
- Tailwind CSS или минимальные CSS-стили проекта;
- `fetch` либо одна выбранная HTTP-библиотека.

## Приоритет интерфейса

Интерфейс должен ясно демонстрировать основной образовательный сценарий. Визуальная необычность не должна ухудшать понятность, скорость или надёжность.

## Обязательные состояния

Для основного действия реализуй:

- начальное состояние;
- ввод данных;
- загрузку;
- успешный результат;
- пустой результат;
- ошибку валидации;
- недоступность backend или AI API.

## Правила реализации

- Получай URL API из переменной окружения Vite.
- Типы запросов и ответов должны соответствовать `API_CONTRACT.md`.
- Не храни ключ OpenAI во frontend и не вызывай OpenAI напрямую из браузера.
- Не используй захардкоженный успешный ответ в конкурсном сценарии.
- Mock-данные допускаются только до интеграции и должны легко отключаться.
- Не добавляй сложную маршрутизацию и глобальное состояние, если продукт состоит из одного основного сценария.
- Показывай пользователю понятные ошибки без технических stack trace.
- Не меняй файлы `backend/`, если задача не требует совместного исправления.
- Перед завершением проверь основной сценарий при запуске через Docker Compose.
