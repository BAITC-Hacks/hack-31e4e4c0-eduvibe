# Hackathon Codex Kit

Набор контекстных шаблонов для команды Dex и B_l_a_c_kS_u_n в образовательном треке пятичасового хакатона.

В комплекте нет бизнес-логики конкурсного решения. После официального старта скопируйте нужные файлы в созданный платформой репозиторий и заполните их по опубликованной задаче.

## Как использовать

1. Скопировать `AGENTS.md` в корень официального репозитория.
2. Скопировать `backend-AGENTS.md` как `backend/AGENTS.md`.
3. Скопировать `frontend-AGENTS.md` как `frontend/AGENTS.md`.
4. Остальные Markdown-файлы поместить в корень.
5. Скопировать опубликованное условие в `TASK_BRIEF.md`.
6. Выполнить запрос из `DAY_OF_PROMPT.md`.
7. После согласования MVP заменить `README_TEMPLATE.md` настоящим `README.md` проекта.

## Важно

- Проверьте актуальные правила и методику конкретной задачи.
- Укажите комплект в `PREEXISTING_MATERIALS.md` как заранее подготовленные шаблоны документации.
- Не оставляйте незаполненные утверждения и примеры в итоговом README.
- Не переносите в конкурсный репозиторий файлы, которые не собираетесь использовать.
