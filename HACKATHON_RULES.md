# Выжимка правил хакатона

Этот файл не заменяет официальное положение. При расхождении действует опубликованное организатором положение и методика конкретного кейса.

## Существенные условия

- Конкретная задача публикуется с началом хакатона.
- Соревновательная разработка занимает 5 часов.
- Основным является автоматически созданный платформой репозиторий команды.
- После завершения соревновательной части репозиторий закрывается для изменений.
- Каждый час команда должна иметь подтверждаемый промежуточный результат.
- Организатор может проверять историю Git, метаданные, работоспособность и вклад каждого участника.
- Разрешены AI-инструменты и AI-агенты.
- Ранее созданный код, библиотеки, модели, шаблоны, датасеты и другие внешние материалы необходимо раскрыть.
- При проверке учитывается конкурсная версия на момент закрытия репозитория.
- Пояснения после закрытия могут объяснять запуск, но не могут изменять код, зависимости, данные или алгоритмы.

## Критерии

| Критерий | Баллы |
|---|---:|
| Соответствие кейсу и функциональность | 20 |
| Техническая реализация | 25 |
| README и техническая документация | 20 |
| Воспроизводимость и развёртывание | 20 |
| Надёжность и безопасность | 15 |
| Итого | 100 |

## Практическое следствие

Сначала выполняются условия допуска и сквозной сценарий. README, Docker и обработка ошибок являются частью конкурсного продукта, а не задачами «если останется время».
